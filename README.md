# Alegria Geleias

SPA da linha de geleias artesanais de Curitiba. React + JavaScript puro, build com Vite, roteamento com React Router.

## Rodando localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Estrutura

- `src/components` — Header, Footer, ProductCard
- `src/pages` — Home, Produtos, Sobre, Contato
- `src/data/produtos.js` — catálogo de sabores (mock)
